R2P MCP Server

The Model Context Protocol (MCP) backend is running successfully. This server provides AI-powered academic report analysis and tool integrations.

Environment Configuration

To fully utilize the authentication and secure API key storage features, ensure the following environment variables are properly set in your deployment:

  • SUPABASE_URL Your Supabase project URL (e.g., https://xyz.supabase.co)
  • SUPABASE_ANON_KEY The anonymous public key for client requests
  • SUPABASE_SERVICE_ROLE_KEY The admin key for bypassing RLS during user operations
  • AES_KEY A 32-byte hex or base64 encoded string used to encrypt third-party API keys at rest. If not set, keys will be stored in base64.

Core Endpoints

  • POST /mcp — Primary JSON-RPC endpoint for tool execution
  • GET /sse — Server-Sent Events stream for asynchronous results
  • GET /tools — List all registered MCP tools
  • GET /health — Basic health check and status
